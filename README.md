# HN Architects Website

Official website source for [HN Architects](https://hassannawazarchitects.com), a premium architecture and interior design studio based in Islamabad, Pakistan.

HN Architects works across residential architecture, luxury villas, interior design, exterior design, commercial architecture, landscape design, 3D architectural visualization, renovation, space planning, turnkey projects, and design consultancy.

## Project Overview

This Astro website is built as a fast, static, search-friendly portfolio and lead generation website for an architecture studio. The site emphasizes visual project storytelling, crawlable service pages, structured data, image sitemaps, AI-readable context, accessible navigation, and a lightweight front end.

Key sections include:

- Architecture and interior design service pages
- Project portfolio and case-study style project pages
- SEO-focused architecture insights
- Contact and consultation flow
- XML sitemap and image sitemap
- `robots.txt` and `llms.txt` routes
- Organization, LocalBusiness, Breadcrumb, Article, FAQ, Service, and CreativeWork schema

## SEO And AI Visibility

The site is structured for modern search and AI discovery without keyword stuffing or manipulative linking.

Implemented visibility foundations:

- Semantic HTML and crawlable static routes
- Canonical URLs
- Optimized page titles and meta descriptions
- Open Graph and Twitter card metadata
- Schema.org JSON-LD for business, content, services, and projects
- AI-readable `llms.txt`
- XML sitemap and image sitemap
- Responsive image delivery with AVIF/WebP assets
- Natural branded agency attribution
